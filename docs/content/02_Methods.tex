\section{Methods}

To be able to solve the Schrödinger's Equation $H\psi = E\psi$, we'll first need to discretize the space and then solve the resulting eigenvalue problem. We'll need to impose the Dirichlet conditions to the domain, which means that the wavefunction $\psi$ must vanish at the boundaries of the billiard.

\begin{equation}
    \left. \psi \right|_{\partial \Omega} = 0
    \label{eq:Dirichlet_condition}
\end{equation}

All the methods used in this project are implemented in Python, and the code is available in the GitHub repository \url{https://github.com/l3l3ss/PCS-Project-}. To explain the followed procedure, we'll first introduce the Mascara method, which is used to discretize the system, and then the Finite Difference Method, which is used to solve the resulting eigenvalue problem.
